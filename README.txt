Para GitHub Pages:

2. Settings > Pages > Deploy from a branch > main > /(root).
3. Salve e aguarde a publicação.

Importante: a seção Mensagens desta versão é local ao navegador (localStorage). Para que mensagens de convidados apareçam para TODOS os visitantes, é necessário conectar um backend como Supabase/Firebase. Não há backend configurado neste pacote.
